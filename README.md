\# PM2.5 Forecasting — Master 1 Data Analysis



\## Project Description



This project focuses on forecasting daily surface PM2.5 concentrations using environmental and temporal data.



\## Part 1 — Exploratory Data Analysis (EDA)



This part covers:

\- Dataset exploration and understanding

\- Data quality assessment

\- Missing value analysis

\- PM2.5 distribution and outlier detection

\- Spatial and temporal analysis

\- Data preprocessing

\- Feature preparation

\- Chronological train/test splitting
